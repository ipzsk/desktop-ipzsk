# IPZSK Desktop 2.0.6

插件市场直接显示 IPZSK 后台审核过的 GitHub 插件。支持单独安装、检查更新和原位升级，完成后重启客户端即可生效；插件更新无需重装主程序。

- 首款插件：IPZSK 生图 1.6.0，来自 JayceHuang/dsh-imagegen。
- 安装前核验精确版本、包名与 SHA-256，并保存恢复检查点。
- 主程序更新源切换为 IPZSK，按操作系统与处理器架构匹配安装包。
- 保留可选的 dsh-market。

本次安装包适用于 macOS Apple Silicon（M 系列芯片），未进行开发者签名公证。旧版首次需手动安装本版；之后客户端和插件各走自己的更新流程。账户、插件与历史数据位于应用包之外。

验证：原作者插件 1.5.6 → GitHub 审核版 1.6.0 的实际升级通过；生图插件完整冒烟测试、市场边界及界面测试、客户端更新与账户测试、后台回归通过。
